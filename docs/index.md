# NestJS Framework

![NestJS Logo](img/nestjs-logo.svg)

Bienvenido a la documentación de **NestJS**, un framework progresivo de Node.js para construir aplicaciones del lado del servidor eficientes, escalables y confiables.

## ¿Qué es NestJS?

NestJS es un framework de Node.js que utiliza TypeScript por defecto y sigue una arquitectura basada en **módulos** similar a Angular. Combina elementos de la programación orientada a objetos, funcional reactiva y funcional para crear aplicaciones backend robustas.

## Características Principales

| Característica | Descripción |
|----------------|-------------|
| **TypeScript** | Tipado estático out of the box |
| **Arquitectura Modular** | Organización en módulos reutilizables |
| **Inyección de Dependencias** | Contenedor IoC integrado |
| **Decoradores** | Sintaxis declarativa para rutas, servicios, etc. |
| **Soporte para WebSockets** | Comunicación en tiempo real |
| **ORM Integrado** | Compatible con TypeORM, Prisma, Mongoose |

## Comparación con Otros Frameworks

| Aspecto | NestJS | Express | Fastify |
|---------|--------|---------|---------|
| TypeScript | Nativo | Opcional | Opcional |
| Arquitectura | Modular | Mínima | Mínima |
| Inyección de Dependencias | Sí | No | No |
| Validación | Built-in | Manual | Manual |
| Curva de Aprendizaje | Media | Baja | Baja |
